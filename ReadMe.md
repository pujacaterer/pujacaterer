# Puja Caterer - Menu & Catering Website

A responsive website for Puja Caterer, a full-service catering, planning, and hosting business based in Ranchi. The website showcases a multi-cuisine menu and provides contact information for bookings.

## Features

- Multi-cuisine menu displayed as an image gallery.
- Contact information with clickable phone numbers, email links, and a Google Maps address.
- Search bar for menu items (placeholder functionality).
- Social media and Open Graph meta tags for better sharing.

## Technologies Used

- **HTML5**: For the structure of the website.
- **CSS3**: For styling the website.
- **JavaScript**: For interactive features.
- **Font Awesome**: For icons.
- **Google Maps API**: For the address link.
- **IntelliJ IDEA**: Development environment.
